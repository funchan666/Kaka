# Kaka 真实业务接入开发计划

> 本计划按用户确认的范围执行。功能必须从 Kaka 的实际入口触发，进度按静态证据和运行证据分别记录。

**目标**是接通参考服务支持的真实业务，并以 Kaka 的说唱房间、词谱和账号流程呈现。参考 ZIP 提供接口、字段、鉴权、数据和第三方协议说明。客户端源码独立编写，产品继续使用 React Native、UIKit 宿主和本地 WKWebView。

## 全局约束

- Kaka 保留自己的 Bundle ID、界面和原创素材。参考连接参数集中到本机忽略配置，按现有线上协议使用，不将服务端密钥随包分发。
- 客户端统一英语，启动和登录不依据审核身份、设备标识或地区切换数据。退出后清除该会话的服务状态。
- 后端令牌只存原生 Keychain。WebView 用当前会话凭据调用限定命令，业务页面无法提交任意 URL。HTTPS 静态媒体可由服务响应提供。
- 按可用宽度、实际安全区和键盘调整现有页面。几何变化复用当前路由、会话和媒体生命周期。
- 静态核对 Swift、JavaScript、Xcode 配置、ZIP 及接口合同。编译、模拟器、真实充值、云端写入及设备验收只在明确授权范围内执行。

## 开发任务

- [ ] **连接与账号**。在 `KakaRemoteClient.swift` 实现 AES 传输、英语头、启动配置和 SAPI 令牌。由 `KakaAccountStore.swift` 处理远端登录、续期、登出和按真实 UID 隔离草稿。认可的旧本机草稿与线上账号分别存储。
- [ ] **桥接与打包**。在 `KakaOfflineView.swift` 验证主框、会话与 payload，将注册、业务命令和退出错误接到 `account.js`、`app.js` 和 `service.js`。验证本机配置有文件引用，分别校验入口归档与更新资源索引。
- [ ] **房间和关系**。接入直播目录与详情、语音目录和主持人资料。把关注、取消关注和举报提交至服务。缺失、空列表、超时、部分服务不可用以及退出登录时显示对应状态。验证有效的房间 ID 与路由解析。
- [ ] **实时功能**。核对 Agora RTC、NIM、Socket、入房和上麦服务的令牌、连接与掉线恢复。直播和语音席必须以 SDK 回调和服务器状态为准。核对私聊、通知、礼物和资料上传服务的端到端责任。
- [ ] **账号资料与安全**。接入档案读取/编辑、支持、条款与隐私。核对拉黑、恢复、删号及密码找回的可用生产路径。对参考项目本身明确不可用的接口记录缺失契约。
- [ ] **充值和权益**。在 `KakaCommerce.swift` 和 `commerce.js` 连接资格、SKU、Apple localized price、订单、交易回执确认、奖励、恢复和余额。成交和奖励以服务确认结果为准。
- [ ] **词谱**。按当前主题、节拍、韵式与小节结构验证真实生成响应。给英语推理接口准备独立客户端调用。私有模型密钥由服务器管理。保留使用者已经保存的歌词和随设备保存的实际草稿。
- [ ] **接入验收**。检查真实路径及失败状态，逐项记录已接通、源码可用但未联调和缺少生产契约的功能。清除旧审核 mock、语言选择、文案中的离线假定和未被调用的占位逻辑。

## 已识别的外部前提

- 参考服务已有邮箱认证、资料、目录、关系、举报、充值和奖励等契约。参考的账号删除和密码恢复在生产路径明确报不可用。
- 语音/视频通过第三方实时通道处理。直播目录记录含频道标识和权限服务，不能将随包预览当作直播。
- 参考词谱/助手推理使用直接供应商 API。可发布版需要服务端推理入口或已授权的代理配置。支付商品需要由 Kaka 的 App Store 商品和后端身份实际返回。
