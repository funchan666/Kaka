# Kaka 真实业务接入开发计划

> 本页保留旧版宿主和服务桥接的接入记录。Kaka 当前使用 Swift、UIKit 和 SwiftUI，工程入口见 [工具链](../../TECH_STACK.md)。

**目标**是接通参考服务支持的真实业务，并以 Kaka 的说唱房间、词谱和账号流程呈现。参考 ZIP 提供接口、字段、鉴权、数据和第三方协议说明。下文保留当时 React Native、UIKit 宿主和本地 WKWebView 的实现路径。

## 全局约束

- Kaka 保留自己的 Bundle ID、界面和原创素材。参考连接参数集中到本机忽略配置，按现有线上协议使用，不将服务端密钥随包分发。
- 客户端统一英语，启动和登录不依据审核身份、设备标识或地区切换数据。退出后清除该会话的服务状态。
- 后端令牌只存原生 Keychain。WebView 用当前会话凭据调用限定命令，业务页面无法提交任意 URL。HTTPS 静态媒体可由服务响应提供。
- 按可用宽度、实际安全区和键盘调整现有页面。几何变化复用当前路由、会话和媒体生命周期。
- 静态核对 Swift、JavaScript、Xcode 配置、ZIP 及接口合同。编译、模拟器、真实充值、云端写入及设备验收只在明确授权范围内执行。

## 开发任务

- [x] **连接与账号**。实现 AES 传输、英语请求头、启动和 SAPI 令牌、邮箱登录与注册、续期和登出。旧本机草稿与线上账号分别存储。
- [x] **桥接与打包**。校验主框、会话及命令输入。配置暂用参考客户端参数，存于 Git 忽略文件。更新版本 4 归档和摘要索引。
- [x] **房间和关系**。接入直播详情、语音目录、主持人资料、关注、取消关注及服务端举报。原生 NIM 查询和维护黑名单。
- [x] **实时房间与消息主流程**。接入 Agora 直播观看、语音收听、麦位、麦克风、WSS 心跳、NIM 房间文字聊天、主持人文字私聊和普通直播礼物。
- [ ] **其他实时和社交业务**。补齐房主开播与管理、PK、私密音视频通话、推送和消息中心、动态、完整发现与各场景通用礼物。
- [x] **资料与帮助**。接入资料读取、艺名和简介修改、签名头像上传、FAQ 和原生协议阅读。
- [ ] **账号管理剩余契约**。提供找回密码和删除账号的生产协议，并为 Kaka 配置 Apple 账号权限及对应后端 audience。客服 NIM 团队会话需要继续接通。
- [x] **充值和权益**。连接实际 App Store 价格、订单、回执、到帐确认、补单、恢复、余额、奖励和等级。商品归属和真实结算待沙盒验证。
- [ ] **词谱**。按当前主题、节拍、韵式与小节结构验证真实生成响应。给英语推理接口准备独立客户端调用。私有模型密钥由服务器管理。保留使用者已经保存的歌词和随设备保存的实际草稿。
- [x] **静态接入检查**。清除旧审核 mock、离线词谱生成和多语言路径，对照源码、资源、依赖及配置。
- [ ] **运行验收**。编译、设备与双端操作、真实后端及 App Store 沙盒回执待联调。

## 已识别的外部前提

- 参考服务已有邮箱认证、资料、目录、关系、举报、充值和奖励等契约。参考的账号删除和密码恢复在生产路径明确报不可用。
- 语音/视频通过第三方实时通道处理。直播目录记录含频道标识和权限服务，不能将随包预览当作直播。
- 参考词谱/助手推理使用直接供应商 API。可发布版需要服务端推理入口或已授权的代理配置。支付商品需要由 Kaka 的 App Store 商品和后端身份实际返回。
- 对照参考接口与缺口见 [后端能力核对](../../BACKEND_COVERAGE.md)。Apple 4.3 的判断对象包括产品本身，审核规则以官方说明为准。[App Review Guidelines](https://developer.apple.com/app-store/review/guidelines/#spam)
