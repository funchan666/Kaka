# 页面、素材与动作

主页面使用深紫 #100B1A、近白 #FBFBFF 和浅灰紫 #CAC0DA。原创录音室照片为顶部提供柔和环境光，重点操作使用透光材质和局部浅紫色。

| 原生页面 | 主要图层 | 内容与动作 |
| --- | --- | --- |
| 欢迎页 | 唱片店后场说唱人物全屏照，底部以玻璃注册按钮与下方登录链接组成操作区 | 注册或登录 |
| 登录与注册 | 清晰人物照片、半透明底色的表单与独立玻璃主按钮 | 输入凭据、注册时设定艺名、勾选协议后提交 |
| 登录提交中 | 照片渐暗处的小玻璃胶囊、四枚原创节拍键与下方状态文案 | 显示 “Signing in…”，等待登录及资料读取完成，失败后恢复表单 |
| Terms of Use / Privacy Policy | SwiftUI 原生协议页 | 在原生页查看占位，已配置的 HTTPS 链接交给系统打开 |
| 直播列表 | 玻璃筛选、带状态灯和玻璃播放入口的精选封面、短条和封面网格 | 筛选直播间、点按整张卡片直接进房 |
| 直播间 | 紧凑的房间身份栏、加高的原生直播画面、连接反馈和玻璃操作栏 | 自动连接、失败后重试、聊天、写词、收藏、送礼、保存笔记、举报或隐藏 |
| 主持人资料 | 主持人照片、浮动关注按钮与主持的房间 | 关注和取消关注、查看主持的场次 |
| 语音房列表 | 紧凑的快速练习卡、玻璃筛选与 Verse Lab 入口、带封面和锁房标记的横向房间条目 | 前往最近打开的房间排练、打开词谱页、按开放状态及关注筛选、选择语音房 |
| 语音房详情 | 封面作为舞台背景，连接状态、主持与音频操作集中排列，实际出拍时四拍面板亮起 | 开放房直接进房旁听，锁房输入密码后连接。可入座、离座、播放节拍、查看练习提示或带入词谱 |
| 写词 | 原创写词台照片上的主题输入区、玻璃提交按钮及提示卡 | 选题或输入主题、展开节拍和押韵设置、生成或再用题目、逐句编辑、存草稿和排练 |
| 个人页 | 原创黑胶封套资料卡、草稿及收藏操作卡、横滑主持人照片和账号分组列表 | 编辑资料、打开本地草稿或收藏笔记、查看主持档案、恢复隐藏、管理账号和钱包或查看帮助 |
| Launch 与应用启动 | 深蓝紫底、最大 96 点的居中图标、四枚原创玻璃节拍键 | 系统 Launch 显示静态素材，SwiftUI 启动层播放节拍动画，失败时提供重试 |

各主页面直接展示内容和操作。进房、播放、编辑等按钮使用原创图标。悬浮底栏采用系统 Liquid Glass，图标下方提供文字标签。[Apple 自定义 Liquid Glass](https://developer.apple.com/documentation/swiftui/applying-liquid-glass-to-custom-views)

点直播卡片后直接进房，播放器显示连接状态，房间资料校验通过后播放直播。退出房间或进入后台时停止当前连接。正在观看或连接时切到后台，返回前台后自动重连。下一次连接等待上一间的音视频操作结束。节拍控制在实际出拍时高亮，减少动态效果时保留选中颜色和状态文字。

写词助手调用现有配置的生成接口，传入主题、风格、BPM、押韵和小节数。生成状态随请求显示，旧草稿按原有结构打开和保存。
