# 页面、素材与动作

主页面使用深紫 #100B1A、近白 #FBFBFF 和浅灰紫 #CAC0DA。原创录音室照片为顶部提供柔和环境光，重点操作使用透光材质和局部浅紫色。

| 原生页面 | 主要图层 | 内容与动作 |
| --- | --- | --- |
| 欢迎页 | 唱片店后场说唱人物全屏照，底部以玻璃注册按钮与下方登录链接组成操作区 | 注册或登录 |
| 登录与注册 | 清晰人物照片、半透明底色的表单与独立玻璃主按钮 | 输入凭据、注册时设定艺名、勾选协议后提交 |
| 登录提交中 | 照片渐暗处的小玻璃胶囊、四枚原创节拍键与下方状态文案 | 显示 “Signing in…”，等待登录及资料读取完成，失败后恢复表单 |
| Terms of Use / Privacy Policy | SwiftUI 原生协议页 | 在原生页查看占位，已配置的 HTTPS 链接交给系统打开 |
| 直播列表 | 杏色选中标记、横滑分类、On air 精选横幅和 2:3 竖版封面网格 | 浏览、发现本次刷新新增的房间、查看关注、搜索已加载房间、按实际观看数排序、直接进房 |
| 直播间 | 全屏原生视频，顶部为主播、关注和在线聊天成员，底部为公告、聊天、礼物预览和更多 | 自动连接，可看主播资料或私聊、核价后确认送礼、分享房间信息、退出或缩为应用内小窗 |
| 主持人资料 | 主持人照片、浮动关注按钮与主持的房间 | 关注和取消关注、查看主持的场次 |
| 语音房列表 | 青色选中标记、房间轮播、包含封面与真实简介的横卡 | 查看关注与最近加入的房间、搜索已加载房间、按实际人数排序与直接进房 |
| 语音房详情 | 压暗的房间封面、发言席卡片、空麦位网格、底部聊天和麦克风控制 | 开放房直接旁听，锁房输入密码后连接。可点选空麦位、离座、主动开麦、查看在线聊天成员、填入快捷回复或分享房间信息 |
| 写词 | 原创玻璃声波、紧凑输入台、液态玻璃提交按钮、灵感列表和小节编辑区 | 选题或输入主题、展开节拍和押韵设置、生成或再用题目、逐句编辑、存草稿和排练 |
| 个人页 | 原创玻璃唱片封面、草稿与收藏目录、横滑主持人照片和账号分组列表 | 编辑资料、打开本地草稿或收藏笔记、查看主持档案、恢复隐藏、管理账号和钱包或查看帮助 |
| Launch 与应用启动 | 深蓝紫底、最大 96 点的居中图标、四枚原创玻璃节拍键 | 系统 Launch 显示静态素材，SwiftUI 启动层播放节拍动画，失败时提供重试 |

各主页面直接展示内容和操作。进房、播放、编辑等按钮使用原创图标。悬浮底栏采用系统 Liquid Glass 和原创图标，VoiceOver 可读取各项名称。[Apple 自定义 Liquid Glass](https://developer.apple.com/documentation/swiftui/applying-liquid-glass-to-custom-views)

点直播卡片后直接进房。连接中和等待主播画面时，用压暗的房间封面作背景并显示对应状态。全屏和应用内小窗使用同一个观众会话。退出房间、进入另一间房或进入后台时结束当前连接。从后台回到当前房间后自动重连。新进房会等待上一间完成音视频清理。节拍控制在实际出拍时高亮，减少动态效果时保留选中颜色和状态文字。

写词助手调用现有配置的生成接口，传入主题、风格、BPM、押韵和小节数。生成状态随请求显示，旧草稿按原有结构打开和保存。
