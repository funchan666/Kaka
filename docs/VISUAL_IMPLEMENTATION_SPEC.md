# 页面、素材与动作

主色为墨蓝 #090A17，前景 #FBFAFF，辅助文字 #CCCDE5。冷蓝 #AABAFF 和暖粉 #FFC0ED 来自舞台光色。按钮用透光底色、背景模糊和渐隐的高光形成玻璃材质，主操作用紫粉色玻璃区分。

| 路由 | 主要图层 | 内容与动作 |
| --- | --- | --- |
| #welcome | 唱片店后场说唱人物全屏照，底部以玻璃注册按钮与下方登录链接组成操作区 | 注册或登录 |
| #login / #register | 清晰人物照片、延伸到玻璃背后的照片色彩、内缩的浮动表单 | 输入凭据、注册时设定艺名、勾选协议后提交 |
| #login 提交中 | 照片前的磨砂玻璃状态浮层、应用图标与动态光条 | 显示 “Logging in…”，等待登录及资料读取完成，失败后恢复表单 |
| policies/terms.html / policies/privacy.html | 独立的 WKWebView 阅读页 | 查看协议、关闭回账号表单或个人页 |
| #stage | 横滑精选场次横幅、分类筛选和双列房间卡片。卡片显示封面、房名、主持人、形式和节拍 | 滑动精选、筛选直播间、打开房间详情 |
| #room/场次 | 预览播放器、玻璃信息、房间主题和折叠笔记 | 预览、排练、写词、收藏、保存笔记、记录原因并隐藏 |
| #creator/主持/来源 | 主持人照片、浮动关注按钮与主持的房间 | 关注和取消关注、查看主持的场次 |
| #voice | Quick practice 和 Verse Lab 玻璃快捷入口，下方每排三张房间卡。卡片显示封面、主持人和 BPM | 前往最近打开的房间排练、打开词谱页、选择语音房 |
| #voice/场次 | 房间封面、主持席、自己的位置及随节拍亮起的四拍面板 | 入座或离座、播放节拍、查看练习提示、带入词谱、返回房间列表 |
| #notebook | 原创玻璃声波、房间灵感、底部磨砂输入区、主题气泡和词谱回复 | 选题或输入主题、展开节拍和押韵设置、生成或再用题目、逐句编辑、存草稿和排练 |
| #crate | 原创唱盘封面、叠在封面下沿的磨砂艺名卡、带原创图标的草稿和收藏入口、主持人头像栏 | 编辑资料、打开本地草稿或收藏笔记、查看主持档案、恢复隐藏、展开账号和协议 |
| Launch 与应用启动 | 深蓝紫底、居中应用图标和下方细加载条 | 系统先显示静态加载条，原生和 Web 加载时使用动效，失败时提供重试 |

一级页从主持人、房间、写词主题或艺名卡片开始。页名保留给读屏，进房、播放、编辑等常用按钮使用原创银色图标，筛选和关键确认保留英文文字。悬浮底栏收至 276×54 点以内。iOS 26 及以上以 UIKit 透明 Liquid Glass 承载四枚原创的珠白图标，当前入口有滑动高光。底栏、按钮和确认层均响应降低透明度设置。[Apple 材质指南](https://developer.apple.com/design/human-interface-guidelines/materials)

舞台预览在房间详情中由点击启动。播放条读取当前时间和时长，离开画面、切页和进入后台会停止。首页精选由用户横滑切换。短入场和网页控件按压使用 CSS 过渡，原生底栏以 UIKit 移动选中高光。节拍控制仅在实际出拍时高亮。减少动态效果时以静态画面、选中颜色和状态文字反馈。

写词助手通过现有离线写词提供方按主题、风格、BPM、押韵和小节数生成当前词谱。生成状态随请求显示。提问和词谱回复独立滚动，发送后输入区留给下一题，点主题气泡可带回输入框。旧草稿按原有结构打开和保存。
