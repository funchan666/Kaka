# 页面、素材与动作

主色为墨蓝 #090A17，前景 #FBFAFF，辅助文字 #CCCDE5。冷蓝 #AABAFF 和暖粉 #FFC0ED 来自舞台光色，主动作以冷蓝到浅紫、桃粉做渐变。信息和操作表面的磨砂与亮边会随其背后内容变化。

| 路由 | 主要图层 | 内容与动作 |
| --- | --- | --- |
| #welcome | 唱片咖啡馆全屏照、底部注册胶囊和右上登录入口 | 注册或登录 |
| #login / #register | 独立清晰照片、贴图底部的玻璃表单和下方协议区 | 输入凭据、注册时设定艺名、勾选协议后提交 |
| policies/terms.html / policies/privacy.html | 独立的 WKWebView 阅读页 | 查看协议、关闭回账号表单或个人页 |
| #stage | 霓虹空舞台、封面玻璃信息窗和主持头像 | 筛选、查看场次、从主持人名单进入档案 |
| #room/场次 | 同一个房间的封面和主持头像 | 排练、写词、收藏、保存笔记、记录原因并隐藏 |
| #creator/主持/来源 | 主持头像 | 关注和取消关注、回看主持的场次 |
| #voice | 耳机工作间背景 | 选择房间与排练席、节拍播放、主持档案、带入词谱 |
| #notebook | 笔记本背景 | 设置和生成词谱、逐小节编辑、保存及回到排练 |
| #crate | 唱片背景，艺名与简介直接呈现 | 编辑资料、关注、收藏、草稿、恢复隐藏、账号管理及查看协议 |
| 应用启动与错误 | 深色底与居中状态文字 | 加载资源，失败后重试 |

所有一级页共用同一套原创透明物件图标。选中项通过亮度和玻璃底色区分，并提供当前页语义。确认层复用同一色板和降低透明度设置。
