# 页面、素材与动作

主色为墨蓝 #090A17，前景 #FBFAFF，辅助文字 #CCCDE5。冷蓝 #AABAFF 和暖粉 #FFC0ED 来自舞台光色。浮动控件与操作栏使用中性透光底色、背景模糊和细高光。同行操作共用一层玻璃，主操作以较亮的填色标出。

| 路由 | 主要图层 | 内容与动作 |
| --- | --- | --- |
| #welcome | 唱片店后场说唱人物全屏照，底部以玻璃注册按钮与下方登录链接组成操作区 | 注册或登录 |
| #login / #register | 清晰人物照片、半透明底色的表单与独立玻璃主按钮 | 输入凭据、注册时设定艺名、勾选协议后提交 |
| #login 提交中 | 照片渐暗处的小玻璃胶囊、四枚原创节拍键与下方状态文案 | 显示 “Signing in…”，等待登录及资料读取完成，失败后恢复表单 |
| Terms of Use / Privacy Policy | SwiftUI 原生协议页 | 在原生页查看占位，已配置的 HTTPS 链接交给系统打开 |
| #stage | 文字筛选与选中下划线、图文分栏主推卡、短卡和可变列数的封面网格 | 筛选直播间、点按整张卡片直接进房 |
| #room/场次 | 紧凑的房间身份栏、加高的原生直播画面、连接反馈和玻璃操作栏 | 自动连接、失败后重试、聊天、写词、收藏、送礼、保存笔记、举报或隐藏 |
| #creator/主持/来源 | 主持人照片、浮动关注按钮与主持的房间 | 关注和取消关注、查看主持的场次 |
| #voice | 原创录音台摄影的快速练习卡、Verse Lab 文字入口、带封面和锁房标记的横向房间条目 | 前往最近打开的房间排练、打开词谱页、按开放状态及关注筛选、选择语音房 |
| #voice/场次 | 封面作为舞台背景，主持和音频入口集中排列，实际出拍时四拍面板亮起 | 监听、入座或离座、播放节拍、查看练习提示、带入词谱、返回房间列表 |
| #notebook | 原创写词台横幅、内置和房间灵感、带字数和琥珀色提交键的底部输入区 | 选题或输入主题、展开节拍和押韵设置、生成或再用题目、逐句编辑、存草稿和排练 |
| #crate | 原创黑胶封套资料卡、草稿及收藏操作卡、横滑主持人照片和账号分组列表 | 编辑资料、打开本地草稿或收藏笔记、查看主持档案、恢复隐藏、管理账号和钱包或查看帮助 |
| Launch 与应用启动 | 深蓝紫底、最大 96 点的居中图标、四枚原创玻璃节拍键 | 系统显示静态素材，原生和 Web 启动使用错时节拍，失败时提供重试 |

直播和语音首页用页名引导筛选，其余一级页从写词主题或艺名卡片开始。进房、播放、编辑等常用按钮使用原创图标。iOS 26 及以上用 SwiftUI Liquid Glass 承载底栏和主要按钮。开启降低透明度时显示实色材质。[Apple 材质指南](https://developer.apple.com/design/human-interface-guidelines/materials)

打开直播间后，房间资料校验通过即发起直播连接。退出房间或进入后台时停止当前直播连接，再切入下一间时等待上一间的音视频操作结束。精选和双列卡片都可直接进房。节拍控制在实际出拍时高亮，减少动态效果时保留选中颜色和状态文字。

写词助手调用现有配置的生成接口，传入主题、风格、BPM、押韵和小节数。生成状态随请求显示，旧草稿按原有结构打开和保存。
