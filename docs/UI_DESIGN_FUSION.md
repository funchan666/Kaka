# 界面方向与适配

欢迎页使用唱片店后场的竖版说唱人物照铺满屏幕。女主手持麦克风，黑色街头穿搭、自然肤质和暖紫侧光呈现一场小型即兴聚会。“Pull up a chair.”、玻璃注册按钮和下方登录入口集中在画面的暗部。登录页的照片是老朋友在卡座交谈，注册页的照片是朋友一起写词。两页都使用内缩的浮动表单。字段按行集中排列，较窄的容器中标签与输入上下排列。协议区位于提交按钮下方。Live 做房间发现，Voice 提供排练席，Write 是逐小节的英文词谱编辑器，Profile 集中关注、作品、收藏及账号管理。

照片保留暖灯和傍晚窗光，背景色透入半透明表单。欢迎、登录和注册的主按钮与表单一起参与 SwiftUI 布局和键盘避让。iOS 26 起使用系统 Liquid Glass，早期版本使用系统薄材质，开启降低透明度时使用实色底。房间与排练界面使用墨蓝底、冷蓝台灯和玫红边光。[Apple 材质指南](https://developer.apple.com/design/human-interface-guidelines/materials)

系统 Launch 和 SwiftUI 加载页采用同一幅居中的应用图标，显示宽度上限为 96 点，随安全区收缩。四枚原创玻璃节拍键放在图标下方。系统显示静态画面，应用开始加载后以同样的画幅逐拍起伏。开启减少动态效果时显示静态节拍键。[Apple 启动界面指南](https://developer.apple.com/documentation/xcode/specifying-your-apps-launch-screen)

登录请求发出后，表单暂时收起。小型玻璃胶囊落在照片渐暗处，四枚玻璃节拍键逐拍起伏，下方显示 “Signing in…”。读屏读取登录状态。开启减少动态效果时显示静态节拍，降低透明度时采用实色胶囊。登录失败时恢复表单和错误提示。

直播首页的文字筛选用下划线标记选中项，节目类型随实际房间显示。精选主卡分栏展示房名、观看入口和封面，其他精选房间使用带缩略图的短卡。常规房间用紧凑的封面网格，房名及可用的观看人数或主持人放在图片下方。列数随可用宽度调整，无障碍大字号使用单列。点按整张卡即可进房并自动连接，失败时可在房内重试。

直播列表接近底部时自动续载。首次加载和续载使用随列数变化的骨架卡片，开启减少动态效果时保持静止。如果下一页没有当前筛选的匹配项，列表提供文字入口继续查找。空状态和首屏失败使用原创空舞台照片，按筛选状态提供浏览全部直播、继续查找或重试等入口。

语音房大厅用原创录音台照片承载 Quick practice，标题旁保留 Verse Lab 的文字入口。筛选使用带下划线的文字标签，可切换全部、开放和关注，有锁房时单独显示锁房筛选。房间列表采用横向条目，缩略图、房名和锁房或主持信息并排，宽容器内改为双列。加载、空状态和错误沿用相同的排版和操作风格。房间内将封面化作舞台背景，主持人和音频入口排列在舞台上，入座、播放节拍和练习提示随内容滚动。切回大厅时沿用大厅滚动位置与筛选。

底栏在 iOS 26 起使用 Liquid Glass，开启降低透明度时切到实色回退。[Apple 材质指南](https://developer.apple.com/design/human-interface-guidelines/materials)

写词页以原创暖光写词台照片和衬线标题开场。内置灵感卡可一键填入主题并保留当前写词设置，房间提供独立主题时也可带入来源房间和节奏。底部输入区显示字数、节奏和小节数，琥珀色 Draft verse 按钮提交生成。生成期间显示提交的主题，完成后可逐小节编辑、保存或排练。

个人页用原创黑胶封套照片整合头像、艺名、简介和编辑入口。草稿与收藏为空时各用一张操作卡，窄屏或无障碍大字号改为上下排列。有内容时显示实际数量和条目。关注与推荐主持通过横滑照片条浏览，账号设置、钱包和帮助集中在分隔列表中。

Swift 和 UIKit 管理生命周期、音视频画面及平台流程，SwiftUI 负责应用页面。三张账号入口照片使用 Garden Image 2 的宿主模式制作，iOS 主屏幕图标使用用户提供的原图。英文正文和交互使用系统无衬线字体。[Apple App Icon 指南](https://developer.apple.com/design/human-interface-guidelines/app-icons)

## Duo 静态实现

- 原生视图沿用所属 Scene，随容器更新 WebView frame、各侧安全区和 27.1 的活动预留区域。图片可延伸，按钮和标题按触及的区域避让。
- 欢迎图可延伸到安全区之外，标题与操作留在可用区域内。窄屏账号页上下排，宽容器把表单放到照片右侧。键盘出现时压缩表单上方间距。协议页使用同一 Scene 的独立阅读面板，关闭后恢复原表单和勾选状态。[Apple iPhone Duo 布局指南](https://developer.apple.com/design/human-interface-guidelines/designing-for-iphone-duo)
- 浮动底栏随各侧安全区和活动预留区定位。网页按底栏实测高度为滚动内容预留空间。键盘或确认层出现时隐藏原生底栏，系统开启降低透明度时由网页提供实色底栏。
- 首页按可用容器宽度缩放横幅与双列网格，开合与旋转沿用当前筛选和页面实例。[Apple iPhone Duo 布局指南](https://developer.apple.com/design/human-interface-guidelines/designing-for-iphone-duo)
- 键盘显示、旋转和开合只更新样式。Tab、房间选择、各页滚动位置与正在编辑的词谱由当前页面会话保留。离开排练详情或 Scene 失活会停止节拍。
- 写词输入区按可用工作区与底栏占用布局。词谱区和展开的节奏设置能各自滚动，键盘出现时保持当前文本输入可达。
- 个人页根据可用容器宽度调整收藏区列数，艺名和简介可换行。开合时资料编辑沿用同一表单。
- 已核对代码、实际 SDK 声明、原始素材和压缩图。当前版本的页面渲染、交互、编译及设备姿态待实测。
