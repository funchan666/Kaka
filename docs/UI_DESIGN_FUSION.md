# 界面方向与适配

欢迎页使用唱片店后场的竖版说唱人物照铺满屏幕。女主手持麦克风，黑色街头穿搭、自然肤质和暖紫侧光呈现一场小型即兴聚会。“Pull up a chair.”、玻璃注册按钮和下方登录入口集中在画面的暗部。登录页的照片是老朋友在卡座交谈，注册页的照片是朋友一起写词。两页都使用内缩的浮动表单。字段按行集中排列，较窄的容器中标签与输入上下排列。协议区位于提交按钮下方。Live 做房间发现，Voice 提供排练席，Write 是逐小节的英文词谱编辑器，Profile 集中关注、作品、收藏及账号管理。

照片保留暖灯和傍晚窗光，背景颜色延伸到半透明表单背后，面板使用背景模糊与细高光。切页时焦点定位至标题，标题无描边，输入和操作控件保有可见焦点。iOS 26 及以上在空间足够且支持透明度时用 UIKit Liquid Glass 显示欢迎页注册按钮。普通网页按钮随内容滚动和缩放。开启降低透明度时使用实色底。房间与排练界面使用墨蓝底、冷蓝台灯和玫红边光。[Apple 材质指南](https://developer.apple.com/design/human-interface-guidelines/materials)

系统 Launch、原生加载和 Web 启动使用同一幅居中的应用图标。底色从标识的蓝紫色取样并压暗，下方放浅紫色细加载条。系统 Launch 保存加载条的静态状态，应用接管后显示扫光，开启减少动态效果时保持静止。[Apple 启动界面指南](https://developer.apple.com/documentation/xcode/specifying-your-apps-launch-screen)

有效登录请求发出后，表单暂时收起。登录照片前的小型磨砂状态浮层也使用同一应用图标。状态文字可由读屏读取，开启减少动态效果时光条保持静止。快速登录保留短暂的显示时间，失败时立即恢复表单和错误提示。

首页先展示可横滑的精选房间横幅，下一张横幅露出一角。下面是分类筛选与双列房间卡片，房名和主持人头像放在封面下方。横幅和卡片进入同一房间详情，可播放舞台片段、打开主持档案、排练或写词。

语音房大厅顶部有 Quick practice 和 Verse Lab 两个快捷入口。Quick practice 显示最近打开的房间和节拍，首次使用时指向首个可用房间。房间列表每排三张，主持人头像叠在方形封面上，房名和 BPM 在封面下方。打开房间后可入座、播放节拍和查看练习提示。切回大厅时沿用大厅的滚动位置。

写词页以冰蓝和淡紫的玻璃声波开场，房间主持头像配合灵感选题。底部输入区使用透明磨砂材质，节奏、风格和押韵收在可展开的设置里。发送主题后，右侧气泡回显题目，左侧玻璃回复可逐小节编辑。

个人页让唱盘的蓝紫灯光透过浮动艺名卡。草稿和收藏为空时并排展示原创图标入口，有内容时以列表显示实际数量和笔记。关注区可进入主持档案，账号设置可展开查看协议和账号操作。

使用马甲包的 RN 和本地 WebView 架构、UI Design Reference、UI Taste、Impeccable 文本流程、Claude Design 和 Garden Web Design Engineer。三张账号入口照片使用 Garden Image 2 的宿主模式制作。账号页用 Avenir Next 组织层级，英文正文和交互使用系统无衬线字体。iOS 主屏幕图标使用正方形画布，交由系统裁切外形。[Apple App Icon 指南](https://developer.apple.com/design/human-interface-guidelines/app-icons)

## Duo 静态实现

- 原生视图沿用所属 Scene，随容器更新 WebView frame、各侧安全区和 27.1 的活动预留区域。图片可延伸，按钮和标题按触及的区域避让。
- 欢迎图可延伸到安全区之外，标题与操作留在可用区域内。窄屏账号页上下排，宽容器把表单放到照片右侧。键盘出现时压缩表单上方间距。协议页使用同一 Scene 的独立阅读面板，关闭后恢复原表单和勾选状态。[Apple iPhone Duo 布局指南](https://developer.apple.com/design/human-interface-guidelines/designing-for-iphone-duo)
- 浮动底栏随各侧安全区和活动预留区定位。网页按底栏实测高度为滚动内容预留空间。键盘或确认层出现时隐藏原生底栏，系统开启降低透明度时由网页提供实色底栏。
- 首页按可用容器宽度缩放横幅与双列网格，开合与旋转沿用当前筛选和页面实例。[Apple iPhone Duo 布局指南](https://developer.apple.com/design/human-interface-guidelines/designing-for-iphone-duo)
- 键盘显示、旋转和开合只更新样式。Tab、房间选择、各页滚动位置与正在编辑的词谱由当前页面会话保留。离开排练详情或 Scene 失活会停止节拍。
- 写词输入区按可用工作区与底栏占用布局。词谱区和展开的节奏设置能各自滚动，键盘出现时保持当前文本输入可达。
- 个人页根据可用容器宽度调整收藏区列数，艺名和简介可换行。开合时资料编辑沿用同一表单。
- 已核对代码、实际 SDK 声明、原始素材和压缩图。当前版本的页面渲染、交互、编译及设备姿态待实测。
