# 界面方向与适配

界面从用户要求的说唱交流出发。直播首页以房间与主持人为主，真实摄影质感的场景和人物图作为可替换占位。详情保留头像、房间主题和下一步操作。语音页用主持位、排练席和节拍并置表达房间关系。词谱仍是清楚的编辑器，完成后可以带回排练。个人页收拢主持关注、场次和作品。

保留用户指定的四个入口。默认深色选自小型夜间音乐现场，配合墨棕、香槟暖光和自然肤色。浮起的玻璃底栏、顶部栏、排练面板和确认面板有实质背景采样，筛选与二级操作用较轻的半透明表面。标题和歌词维持实体文字。开启降低透明度或缺少背景滤镜时使用实色。

使用马甲包的 RN 和本地 WebView 架构、UI 设计参考、UI Taste、Impeccable 文本流程、Design Skill、Claude Design、Garden Web Design Engineer。原创占位图通过 Garden GPT Image 2 的宿主模式生成和压缩。中文正文用 PingFang SC，英文品牌与 BPM 用 Avenir Next Condensed 或系统回退。未引入外部字体或图标库。

## Duo 静态实现

- 原生视图沿用所属 Scene，随容器更新 WebView frame、各侧安全区和 27.1 的活动预留区域。图片可延伸，按钮和标题按触及的区域避让。
- Web 使用容器宽度变化将房间、排练、词谱和个人内容从单列重排到双列。边距和顶部及底部按钮按各自区域计算。
- 可见 viewport 缩小并且正在输入时收起浮动底栏。正常浏览按底栏实测高度为滚动内容预留空间。
- 键盘显示、旋转和开合只更新样式。Tab、房间选择、各页滚动位置与正在编辑的词谱由当前页面会话保留。切离语音页或 Scene 失活会停止节拍。
- 已核对代码、SDK 声明、原始素材和压缩图。尚未运行页面渲染和交互，外屏、内屏、半折、分屏、大字体、键盘、音频与触控尚待实际设备验证。
