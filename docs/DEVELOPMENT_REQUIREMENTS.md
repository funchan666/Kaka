# Kaka 离线框架

项目起点为空仓库，Kaka 取自现有目录名。首版按用户指定顺序保留四个入口。目标用户暂按想找说唱同好、练即兴和写词的普通爱好者设计。

| 页面 | 离线能力 |
| --- | --- |
| 直播间 | 按开放麦、即兴接力和伴奏筛选示例场次。点开房间查看主题、主持档案和速度，可关注、收藏、记排练笔记或隐藏场次。 |
| 语音房 | 选房间并加入排练席，播放四拍节拍器。可以按房间速度去写词，也可以把编辑中的词谱带回排练。 |
| AI 词谱 | 输入主题，设置 60 至 180 BPM、风格、4/8/16 小节和 AABB/ABAB 韵式。逐小节编辑，查看目标韵脚和起拍或换气提示，按需保存。 |
| 我的 | 编辑艺名、风格和简介，回看词谱草稿、收藏、笔记和关注的示例主持人，恢复已隐藏的场次。 |

主流程从节目单进入房间，沿用房间主题与节拍写词，带回排练并保存在个人页。示例主持和照片是内容占位，关注、收藏、举报记录都来自使用者的主动操作。举报入口记录原因并隐藏场次，之后可恢复。

本阶段使用设备内个人资料。正式签名、账户、直播、多人连麦、远端消息、线上模型、内购及协议等随对应服务再确定。没有商品 ID 或发行主体；本阶段清单据实记录。完整马甲包的发布级校验包含正式产品和商业配置，因此这份离线清单不满足其发布模板。
